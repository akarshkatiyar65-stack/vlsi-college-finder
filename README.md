# VLSI College Finder

A simple web-based college comparison tool for comparing M.Tech VLSI, Embedded Systems, ECE, and related specializations.

Features

* Compare colleges and specializations
* GATE cutoff comparison
* Seat/strength information
* Internship offers and internship percentage
* Full-time placement offers
* Average package / CTC
* Search colleges
* Sort colleges by different parameters
* Clean, responsive interface

Data

The data in this project is collected and added manually.
`NA` means that the information is currently unavailable.

Website

The website is deployed using GitHub Pages.

Technologies

* HTML
* CSS
* JavaScript
